What it does

The boring part of set prep, done for you.

Import a folder, check the results, export. Everything you'd normally set by hand in Rekordbox is already there.

BPM + KEY

Reads every track

Key and tempo detection from a published music-analysis library, rounded the way DJ software shows it (130.00, not 129.9). Fix any read in two clicks.

KEY WHEEL

Shows what blends

Select a track and every compatible key lights up. Switch between number codes like 8A and real key names like Am.

5 CUES

Cue points on the grid

Intro on the first beat, first drop, breakdown, second drop, and an outro 32 bars from the end. Drag any of them and they snap to the beat.

AUTO

Orders your set, every mix in key

One click builds the whole set so each blend is a compatible key move, following the energy shape you pick. Every transition is marked ✓, ~ or ⚠, so you can see at a glance that it works.

RENAME

One file per mix

Add a label like "Club Mix" to every file in a playlist, on disk, so each set keeps its own cues. One click puts the old names back.

EXPORT

Straight to Rekordbox

An XML with keys, BPM, beat grid, color-coded hot cues and your playlists in the exact order you arranged them.

How it works

Folder in, Rekordbox playlist out.

1

Import

Pick a folder or drag it onto BlendKey. Tracks are analyzed once; next time you open the app your whole library is there instantly.

2

Check

Glance down the key and BPM columns and the cue points on each waveform. Correct anything that's off; BlendKey keeps your fixes.

3

Arrange

Drop tracks into a playlist and let Auto order them, or order them yourself using the key wheel.

4

Export

Save the Rekordbox XML. BlendKey already knows where every file lives, so there's no folder path to type.

5

Import in Rekordbox

Point Rekordbox at the XML in Preferences, right-click your playlist, choose Import, then sync to USB as usual.

FAQ

Questions DJs ask

How accurate is the key and BPM detection?

It uses a published, well-tested music-analysis library and matches DJ software on most dance tracks. No detector is perfect, so every key, BPM and cue point can be corrected by hand, and BlendKey remembers your corrections.

Does it change my music files?

Only if you use Rename, which adds a label to the file names in a playlist. The audio itself is never touched, and Revert restores the original names.

How do I move BlendKey to a new computer?

Open BlendKey on the old computer, click BlendKey Pro, then Deactivate this computer. Then activate the same key on the new one. Each key works on 2 computers at once.

Do I need internet to DJ?

No. You need a connection to activate your key. After that BlendKey checks in now and then, and keeps working offline for up to 30 days between checks.

My Mac says Apple can't verify BlendKey.

Drag BlendKey into Applications and open it once. When macOS blocks it, open System Settings → Privacy & Security, scroll down and click Open Anyway, then confirm. On older macOS versions you can instead right-click BlendKey, choose Open, then click Open. You only need to do this the first time.

Windows says "Windows protected your PC".

That's Windows SmartScreen, which shows for new apps it hasn't seen many downloads of yet. Click More info, then Run anyway. You only need to do this when installing.

Which Mac download do I need?

Click the Apple menu → About This Mac. If it says Apple M1, M2, M3 or M4, choose Apple Silicon. If it says Intel, choose Intel.
